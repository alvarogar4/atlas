# Eisenhower Matrix

For prioritizing tasks and decisions based on urgency and importance.

## How to Use

- **Urgent**: Has a deadline or requires immediate attention
- **Important**: Contributes to long-term goals and values

## The Matrix

```
                    URGENT                     NOT URGENT
            ┌─────────────────────────┬─────────────────────────┐
            │                         │                         │
            │      Q1: DO FIRST       │     Q2: SCHEDULE        │
            │                         │                         │
            │   Crises                │   Strategic planning    │
 IMPORTANT  │   Deadlines             │   Relationship building │
            │   Emergencies           │   Learning/growth       │
            │   Last-minute tasks     │   Exercise/health       │
            │                         │   Deep work             │
            │                         │                         │
            ├─────────────────────────┼─────────────────────────┤
            │                         │                         │
            │      Q3: DELEGATE       │     Q4: ELIMINATE       │
            │                         │                         │
            │   Some meetings         │   Time wasters          │
    NOT     │   Some emails           │   Busywork              │
 IMPORTANT  │   Some calls            │   Pleasant activities   │
            │   Other people's        │   Escape activities     │
            │   priorities            │   Excessive social      │
            │                         │   media/news            │
            │                         │                         │
            └─────────────────────────┴─────────────────────────┘
```

## Template

```markdown
## Eisenhower Matrix: {Context/Period}

### Q1: Do First (Urgent + Important)
| Item | Deadline | Action |
|------|----------|--------|
| {task} | {date} | {what to do} |

### Q2: Schedule (Not Urgent + Important)
| Item | When to Do | Time Blocked? |
|------|------------|---------------|
| {task} | {date/time} | {Yes/No} |

### Q3: Delegate (Urgent + Not Important)
| Item | Delegate To | Status |
|------|-------------|--------|
| {task} | {person/tool} | {done/pending} |

### Q4: Eliminate (Not Urgent + Not Important)
| Item | Why Eliminating | Replacement Activity |
|------|-----------------|---------------------|
| {task} | {reason} | {better use of time} |

### Weekly Review
- [ ] Move completed Q1 items out
- [ ] Schedule specific times for Q2 items
- [ ] Find ways to delegate more Q3 items
- [ ] Ruthlessly eliminate Q4 activities
```
