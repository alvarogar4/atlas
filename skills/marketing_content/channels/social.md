# Channel: Social Media (Generic)

Use this guide for social media platforms not covered by the specific channel files (blog, linkedin, twitter, email, hackernews). Applies to Facebook, Instagram, Reddit, Product Hunt, and other platforms.

## Copywriting Frameworks

### PAS (Problem-Agitation-Solution)

```
Problem: {State the pain}
Agitation: {Make it feel urgent}
Solution: {Present your answer}
```

### AIDA (Attention-Interest-Desire-Action)

```
Attention: {Hook}
Interest: {Why care}
Desire: {Paint success}
Action: {Clear CTA}
```

### BAB (Before-After-Bridge)

```
Before: {Current state}
After: {Desired state}
Bridge: {How you get there}
```

### 4Ps (Promise-Picture-Proof-Push)

```
Promise: {What you'll deliver}
Picture: {Visualize the result}
Proof: {Evidence it works}
Push: {CTA with urgency}
```

## Channel Best Practices

### General Social

- Platform-appropriate length (shorter is usually better)
- Engagement-focused (ask questions, invite discussion)
- Clear single CTA
- Visual content outperforms text-only
- Post when your audience is active
- Respond to comments quickly

## CTA Best Practices

| Element         | Best Practice                                               |
| --------------- | ----------------------------------------------------------- |
| Copy            | Action verb + benefit: "Get my free checklist"              |
| Placement       | Above fold + end of page (don't make them scroll both ways) |
| Quantity        | ONE primary CTA per post                                    |
| Personalization | "Start your trial" > "Start a trial"                        |

**Data:**

- Personalized CTAs convert **202% better** (HubSpot)
- Single CTA per email: **371% more clicks**
- "Get Started" beats "Book a Demo" by **111.55%**

## Quality Checklist

### Before Publishing

- [ ] Clear, benefit-focused headline/hook
- [ ] One main message/CTA
- [ ] Appropriate length for platform
- [ ] Proofread for errors
- [ ] Mobile-friendly
- [ ] On brand voice and tone
- [ ] Links work
- [ ] No placeholder text
- [ ] Formatting renders correctly
