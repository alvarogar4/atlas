# Email Writing Guidelines

## Email Anatomy

```
┌─────────────────────────────────────┐
│ FROM: Name <email@domain.com>       │
│ SUBJECT: 30-50 characters           │
│ PREHEADER: 40-90 characters         │
├─────────────────────────────────────┤
│ OPENING: Hook in first line         │
│                                     │
│ BODY: One main message              │
│                                     │
│ CTA: Clear, single action           │
│                                     │
│ P.S.: Optional reinforcement        │
└─────────────────────────────────────┘
```

## Subject Line Formulas

### Character Limits

| Device | Visible Characters |
|--------|-------------------|
| Desktop | 60 characters |
| Mobile | 30-40 characters |
| Optimal | 30-50 characters |

### What Works

| Formula | Example |
|---------|---------|
| Question | "What's holding your business back?" |
| Number + benefit | "3 ways to double your conversion rate" |
| How-to | "How I grew to 10K subscribers in 90 days" |
| Curiosity gap | "The mistake everyone makes (and how to fix it)" |
| Urgency | "Last chance: Offer ends tonight" |
| Personalization | "[Name], your weekly growth tips" |
| Story tease | "I almost quit yesterday..." |
| Direct benefit | "Get more done in less time" |

### Power Words

**Increase opens:** "Free" (+10%), Numbers (+57%), Personalized names (+29%), "You/Your"

**Decrease opens:** "Newsletter" (-18.7%), ALL CAPS, Excessive punctuation, Spam triggers

## Preheader Text

- 40-90 characters
- NEVER repeat the subject line
- Complement the subject with curiosity or benefit
- Add blank spaces after to prevent body text bleeding in

**Example:**
```
Subject: You're leaving money on the table
Preheader: The 3-minute fix that recovered $47k for Sarah...
```

## Email Types

| Type | Format | Length |
|------|--------|--------|
| Newsletter | Consistent format, 1-3 sections, value-first | 200-500 words |
| Promotional | Clear offer, benefit-focused, single CTA | 50-150 words |
| Nurture/Welcome | Personal intro, set expectations, soft CTA | 150-250 words |
| Transactional | Clear purpose, essential info only | Brief |
| Sales | Benefit-focused, social proof | 150-300 words |

## Email Structure (AIDA)

```
ATTENTION: Subject + First line hooks
INTEREST: Why should they care?
DESIRE: Paint the benefit/outcome
ACTION: Clear CTA
```

### Opening Lines That Work

| Technique | Example |
|-----------|---------|
| Direct | "I have something important to share..." |
| Question | "Quick question for you..." |
| Story | "Last week, something happened that..." |
| Personalized | "I noticed you downloaded our guide..." |
| Benefit | "Want to double your email open rates?" |

### What NOT to Start With

- "I hope this email finds you well"
- "Just checking in"
- "It's been a while since..."
- Generic greetings

## CTA Best Practices

### Placement

- Above the fold (primary CTA)
- End of email (repeat CTA)
- ONE primary action per email

### Button Copy

| Weak | Strong |
|------|--------|
| "Click here" | "Get my free checklist" |
| "Submit" | "Start my trial" |
| "Learn more" | "See how it works" |
| "Download" | "Download the playbook" |

### Data-Backed Tips

- Single CTA: 371% more clicks
- Personalized CTAs: 202% better conversion
- "Get Started" beats "Book a Demo" by 111%

## The P.S. Line

One of the most-read parts of an email. Use for:
- Reinforcing the main offer
- Adding urgency
- Secondary CTA
- Personal touch

## 5-Day Launch Sequence

| Day | Purpose | Hook |
|-----|---------|------|
| 1 | Agitate the Problem | Make them FEEL the pain |
| 2 | Tease Solution | Paint the "after" picture |
| 3 | Show Proof | Case studies, testimonials |
| 4 | Details | Pricing, what's included, risk reversal |
| 5 | Close | Deadline, recap benefits, final CTA |

Each email: 150-200 words, ONE idea, curiosity-driven subject lines.

## Email Quality Checklist

- [ ] Subject line is 30-50 characters
- [ ] Preheader complements (not repeats) subject
- [ ] First line hooks attention
- [ ] One main message per email
- [ ] Single primary CTA
- [ ] CTA copy is action-oriented
- [ ] Conversational tone (read aloud test)
- [ ] Paragraphs are short (1-3 sentences)
- [ ] No spam trigger words
- [ ] Mobile-friendly formatting
- [ ] P.S. line adds value (if included)

## What to Avoid

- Multiple CTAs competing for attention
- Walls of text without line breaks
- Corporate/formal tone
- Images without alt text
- Subject lines that don't match content
- No unsubscribe link (required by law)
