# Content Metrics

Reference statistics for content planning. Cite sources when using these figures.

## Blog Post Length

| Length            | Recommendation      | Source    |
| ----------------- | ------------------- | --------- |
| 2,000-2,500 words | Sweet spot for SEO  | Semrush   |
| 3,000+ words      | 56% LESS traffic    | HubSpot   |
| 1,500+ words      | Minimum for ranking | Backlinko |

### Word Count by Content Intent

| Content Type             | Target Length      | When to Use                      |
| ------------------------ | ------------------ | -------------------------------- |
| **Awareness** (TOFU)     | 1,200-1,800 words  | Educational, "what is X" content |
| **Consideration** (MOFU) | 1,500-2,000 words  | Comparisons, "how to choose"     |
| **Decision** (BOFU)      | 2,000-3,000 words  | Deep guides, "ultimate" content  |
| **Quick Answer**         | 500-800 words      | Simple queries, news updates     |
| **Pillar Pages**         | 3,000-4,000+ words | Cornerstone content              |

### The Real Rule

**Cover the topic completely without padding.** A 1,500-word post that answers everything is better than a 3,000-word post with fluff.

## Headlines

### Headline Effectiveness Data

| Element              | Guideline             | Source                      |
| -------------------- | --------------------- | --------------------------- |
| Length               | 6-8 words optimal     | CoSchedule                  |
| Numbers              | Increase CTR by 36%   | Content Marketing Institute |
| Questions            | 23% higher engagement | Backlinko                   |
| Negative headlines   | 60% higher CTR        | Outbrain                    |
| List-based headlines | 36% prefer them       | Buffer                      |

### The 4 U's Checklist (Rate 1-4 each)

- **Useful**: Does it promise a clear benefit?
- **Urgent**: Is there a reason to read NOW?
- **Unique**: What makes this different?
- **Ultra-Specific**: Numbers, details, concrete promises?

### Top 10 Headline Templates

1. "How to [Task] (Even If [Obstacle])"
2. "[Number] [Adjective] Ways to [Desired Result]"
3. "The [Adjective] Guide to [Topic]"
4. "Why [Common Belief] Is Wrong (And What to Do Instead)"
5. "[Number] [Topic] Mistakes (And How to Fix Them)"
6. "What [Expert/Competitor] Won't Tell You About [Topic]"
7. "How I [Achieved Result] in [Timeframe]"
8. "The [Unexpected] Secret to [Desired Outcome]"
9. "[Do This], Not [That]: The [Topic] Guide"
10. "[Topic] for [Audience]: A Complete Guide"

## SEO Guidelines

| Element            | Best Practice                   | Impact     |
| ------------------ | ------------------------------- | ---------- |
| Primary keyword    | Title, H1, URL, first 100 words | High       |
| Secondary keywords | H2s, body naturally             | Medium     |
| Meta description   | 150-160 chars, include keyword  | Medium     |
| Internal links     | 3-5 per 1000 words              | Medium     |
| External links     | 2-3 authoritative sources       | Low-Medium |
